# Проект "Виджет банковских операций"

## Описание проекта
Проект предназначен для обработки и анализа банковских операций клиента. 
Включает функции фильтрации и сортировки операций.

## Установка
Клонируйте репозиторий:
```bash
git clone https://github.com/MaximxLeon/SkyPro.git
```
## Тестирование

Проект покрыт тестами (pytest).  
Для запуска тестов:

```bash
pytest
```
## Модуль generators

Модуль `generators` содержит генераторы для эффективной работы с большими
объёмами транзакционных данных.

### Модуль `masks`

Модуль `masks` предназначен для маскирования конфиденциальных финансовых данных.

Функциональность:
- маскирование номера банковской карты (первые 6 и последние 4 цифры);
- маскирование номера банковского счёта (отображаются только последние 4 цифры);
- логирование всех операций маскирования.

Модуль обеспечивает безопасное отображение данных клиента.

---

### Модуль `utils`

Модуль `utils` отвечает за загрузку и обработку банковских операций из файлов
различных форматов.

Поддерживаемые форматы:
- JSON;
- CSV;
- Excel (XLS/XLSX).

Возможности модуля:
- чтение данных из файлов;
- преобразование данных в единый формат (список словарей);
- обработка ошибок при загрузке файлов;
- логирование процесса загрузки данных;
- подсчёт количества операций в каждой категории по описанию;
- филтрация списка транзакций по ключевому слову в описании.

---

### Модуль `external_api`

Модуль `external_api` используется для конвертации сумм операций в рубли (RUB).

Особенности:
- поддержка валют **USD** и **EUR**;
- конвертация через внешний сервис Exchange Rates Data API;
- использование API-ключа из переменных окружения;
- обработка ошибок HTTP-запросов и неподдерживаемых валют.
